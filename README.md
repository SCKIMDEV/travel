# Travel Diary

여러 여행의 일정과 사진, 기록을 담는 다이어리 웹 페이지입니다. 홈 화면에서 여행 목록을 보고, 여행을 고르면 그 여행의 동선 지도·타임라인·사진·기록이 열립니다.
지금 들어 있는 여행은 **강릉여행 1박 2일 (2026.10.18 — 10.19)** 입니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

## 열기

- 평소에는 공유 주소 **https://sckimdev.github.io/travel/** 를 엽니다. 홈 화면(여행 목록)이 열립니다.
- 여행 하나를 바로 열려면 `https://sckimdev.github.io/travel/trip.html?trip=<여행 id>` (예: `?trip=gangneung`). 없는 id 면 홈으로 돌아갑니다.
- 로컬에서 고치면서 볼 때는 이 폴더에서 아래를 실행하고 http://localhost:8765 로 엽니다.

```bash
python -m http.server 8765
```

- `index.html` 을 더블클릭해서 열어도 목록·일정·지도는 보이지만, 서버 모드에서는 사진·기록을 불러오지 못합니다(서버가 `file://` 출처를 허용하지 않음). 그렇게 쓰려면 `js/trips/manifest.js` 의 `server` 를 비워 브라우저 모드로 두세요.

## 공유 주소 (GitHub Pages)

이 저장소의 `main` 브랜치가 GitHub Pages 로 그대로 공개됩니다.

- 주소: **https://sckimdev.github.io/travel/**
- 파일을 고쳐서 `main` 에 push 하면 1~2분 안에 반영됩니다.
- 사진과 기록은 아래 "데이터가 저장되는 곳" 대로 운영 PC 의 서버에 저장되어, 휴대폰에서 넣은 사진이 PC 에서도 그대로 보입니다.

## 기능

### 홈 화면 (여행 다이어리, `index.html`)

- 여행마다 가죽 표지 다이어리가 한 권씩 놓입니다. 표지에는 권 번호(날짜 순 No.), 제목, 날짜, 지역과 붉은 **D+ 도장**이 있습니다. 다가올 여행이 먼저, 그다음 최근 여행 순입니다.
- D+ 도장은 여행 첫날이 기준일로부터 며칠째인지입니다. 기준일은 `js/trips/manifest.js` 의 `DIARY_CONFIG.dday` (지금 `2026-07-26` = D+1, 강릉여행은 D+85). 날짜(연도)를 모르는 여행은 D+ 대신 `stamp`/`seal` 글자를 찍습니다.
- **마우스를 올리면 다이어리가 펼쳐집니다** (키보드로 Tab 이동해도 펼쳐짐). 안쪽 표지에는 실제 좌표로 그린 동선 지도(붉은 점 = 출발), 첫 장에는 사진 두 장과 사진·장소 수가 보입니다. 사진이 없는 여행은 날짜별 일정을 보여줍니다. 누르면 그 여행 페이지가 열립니다.
- **휴대폰(터치)에서는 첫 탭에 펼치고, 펼친 다이어리를 한 번 더 누르면** 여행 페이지로 갑니다. 바깥을 누르면 접힙니다.
- 표지 색·책갈피 끈 색·도장·첫 장 손글씨·지도의 짧은 지명은 여행 파일의 `diary` 로 정합니다 (없으면 기본값).
- 사진 서버에 닿지 못하면 다이어리와 동선 지도는 그대로 보이고, 상단 바 오른쪽에 붉은 **!** 가 뜹니다. 마우스를 올리거나 누르면 원인과 해결 방법이 펼쳐집니다.

### 여행 페이지 (`trip.html?trip=<id>`)

- **일정 타임라인**: 날짜별 동선과 이동 시간을 보여줍니다. 장소 이름을 누르면 지도에서 그 장소를 보여주고(팝업의 "기록 보기"로 카드로 갈 수 있음), 좌표가 없는 장소나 지도가 뜨지 않았을 때는 그 장소의 기록으로 이동합니다. 사진이나 기록이 있는 장소는 타임라인의 점이 채워집니다. 데스크톱에서는 한 줄, 휴대폰에서는 ㄹ자 두 줄(둘째 줄은 오른쪽 → 왼쪽, 줄 끝은 U자 선으로 연결)로 보이고, 긴 이름은 겹치지 않도록 글자 크기가 조금 줄어듭니다.
- **장소별 다이어리 카드**: 각 장소마다 사진, 방문 시간, 기록을 남길 수 있습니다.
  - `+ 사진` 버튼, 카드 위로 드래그 앤 드롭, 기록 입력 중 이미지 붙여넣기(Ctrl+V) 모두 가능합니다.
  - 사진을 누르면 크게 보기가 열리고, 설명 달기 / 순서 바꾸기 / 파일로 저장 / 삭제를 할 수 있습니다. 키보드 ← → Esc 지원.
- **하루 메모**: 날짜마다 그날 전체에 대한 메모를 남길 수 있습니다.
- **동선 지도**: 표지 아래 지도에 모든 장소가 핀으로 찍히고 날짜별 경로가 점선으로 이어집니다.
  - 전체 / DAY 1 ~ 탭으로 날짜를 골라 볼 수 있습니다. 전체 보기에서는 핀 숫자가 일차, 날짜 보기에서는 그날의 방문 순서입니다. ✦ 는 여러 날 들른 곳입니다.
  - 핀을 누르면 장소 이름과 사진·기록 여부(한 장소 핀이면 첫 사진 썸네일도)가 뜨고 "기록 보기"로 해당 카드로 이동합니다. 사진이나 기록이 있는 장소는 핀이 붉게 바뀝니다. Esc 로 팝업을 닫을 수 있습니다.
  - 카드 제목 옆 핀 아이콘을 누르면 지도에서 그 장소를 보여줍니다.
  - 같은 좌표의 장소(숙소, 역)는 핀 하나로 묶입니다.
  - 휴대폰에서는 지도를 한 번 탭해야 손가락으로 움직일 수 있습니다. 페이지 스크롤을 가로채지 않기 위한 동작입니다. 데스크톱의 휠 줌도 지도를 클릭한 뒤에만 켜집니다.
  - 지도는 Leaflet과 OpenStreetMap 타일을 온라인에서 받아오므로 인터넷이 필요합니다. 오프라인이면 안내 문구만 보이고 나머지 기능은 그대로 동작합니다.
- **자동 저장**: 입력하면 자동으로 저장됩니다.
- **백업**: 화면에 버튼은 없고, 브라우저 콘솔(F12)에서 `TravelDiary.exportBackup()` 으로 사진과 기록 전체를 JSON 파일 하나로 내려받고, `TravelDiary.importBackup(file)` 로 되돌릴 수 있습니다. 다른 여행의 백업을 불러오려 하면 경고가 뜹니다.
- **인쇄**: 브라우저 인쇄(Ctrl+P)로 날짜별 페이지가 나뉜 앨범 형태로 출력됩니다.

## 데이터가 저장되는 곳

`js/trips/manifest.js` 의 `DIARY_CONFIG.server` 값에 따라 두 가지 방식 중 하나로 동작합니다. 모든 여행이 같은 설정을 쓰고, 여행 파일에 `server` 를 따로 적으면 그 여행만 다르게 할 수 있습니다.

**서버 모드 (지금 설정)** — `server: "https://parking.tail7d1054.ts.net:8443"`

- 사진과 기록이 운영 PC 의 [travel-server](https://github.com/SCKIMDEV/travel-server)(Docker) 에 여행 id 별로 따로 저장되어(`data/<id>/`), 어느 기기에서 열어도 같은 내용이 보입니다. 새 여행을 추가해도 서버는 고칠 필요가 없습니다.
- 비밀번호는 없습니다. 서버 접속 키(`serverKey`, 서버 `.env` 의 `DIARY_KEY` 와 같은 값)가 `js/trips/manifest.js` 에 들어 있어 페이지가 알아서 접속합니다. 그래서 **주소를 아는 사람은 누구나 사진을 보고 올리고 지울 수 있습니다.** 키를 바꾸려면 서버 `.env` 와 `serverKey` 를 같은 값으로 함께 바꾸세요.
- 서버 PC 가 꺼져 있거나 브라우저가 연결을 막으면 상단 바 오른쪽에 붉은 **!** 가 뜨고(올리거나 누르면 안내) 일정·지도만 보입니다. 사진 올리기는 막히고, 기록을 입력하면 "NOT SAVED" 표시와 함께 저장되지 않았음을 알려줍니다. 서버가 돌아오면 새로고침하세요.
- 사진 주소에는 비밀번호 대신 읽기 전용 토큰이 들어가므로, 사진 링크를 공유해도 수정·삭제는 할 수 없습니다.
- Tailscale 에 로그인된 기기(서버 PC 포함)에서는 서버 주소가 사설 IP 로 풀려, Chrome·Edge 가 "로컬 네트워크 액세스"를 막을 수 있습니다. 이때 사진이 안 보이면 주소창 왼쪽 아이콘 → 이 사이트에 대한 권한 → "로컬 네트워크 액세스"를 허용하고 새로고침하세요 (붉은 ! 안내가 지금 권한 상태에 맞춰 알려 줌). 사진 자체는 서버에 그대로 있으니 다시 올릴 필요는 없습니다. 서버 PC 의 Tailscale 은 끄면 안 됩니다(모두가 사진 서버에 못 들어옴).

**브라우저 모드** — `server: ""`

- 사진과 기록이 **브라우저의 IndexedDB** 에만 저장되고 서버로 전송되지 않습니다. 여행마다 저장소가 따로입니다(`storageKey`).
- 브라우저 데이터를 지우거나 다른 브라우저/기기에서 열면 보이지 않으므로 콘솔의 `TravelDiary.exportBackup()` 으로 파일을 남겨 두세요.

공통

- 사진은 저장 용량을 위해 긴 변 2048px JPEG 로 줄여서 저장합니다. 원본은 따로 보관하세요. (크기는 `js/app.js` 상단의 `MAX_FULL` 로 조절)
- HEIC(아이폰 기본 포맷)는 브라우저가 열지 못하므로 JPEG 로 변환해서 넣어야 합니다.
- 백업(`exportBackup` / `importBackup`)은 두 모드 모두에서 동작하며, 모드 사이에 데이터를 옮길 때도 쓸 수 있습니다.

## 여행 추가와 일정 수정

여행 하나가 파일 하나입니다 (`js/trips/<이름>.js`). 그 파일을 고치면 홈 화면 카드와 여행 페이지에 함께 반영됩니다.

**새 여행 추가**

1. `js/trips/gangneung.js` 를 복사해 `js/trips/<이름>.js` 를 만들고 내용을 바꿉니다. `id` 는 영문 소문자·숫자·`-` 만 씁니다 (서버 폴더 이름과 주소에 쓰임).
2. `js/trips/manifest.js` 의 `TRIP_FILES` 에 `<이름>` 을 넣습니다.
3. push 하면 홈 화면에 카드가 생기고 `trip.html?trip=<id>` 로 열립니다.

```js
registerTrip((() => {
  const HOTEL = { lat: 37.785187, lng: 128.928717 };   // 여러 번 나오는 숙소 좌표 (선택)
  return {
    place: "강원 강릉",            // 홈 화면에 보이는 지역
    start: "2026-10-18",          // 여행 날짜 (홈 화면의 연도 묶음·정렬)
    end: "2026-10-19",
    // planned: true,             // 아직 날짜를 모르는 다가올 여행이면 start/end 대신
    id: "gangneung",              // 여행 구분자 (주소, 서버 폴더, 백업 파일 이름)
    storageKey: "gangneung-diary", // 브라우저 모드 저장소 이름
    title: "강릉여행",             // 큰 제목 (한글은 명조체, 영문은 Playfair 로 표시)
    brand: "Gangneung Diary",     // 여행 페이지 상단 바 이름과 탭 제목
    seal: "",                     // 여행 페이지 오른쪽 위 붉은 도장 글자 (비우면 숨김, 예: "江陵")
    diary: {                      // 홈 화면 다이어리 모양 (모두 선택)
      cover: "#1f3a44",           //   표지 가죽색
      ribbon: "#b23a2a",          //   책갈피 끈 색
      stamp: "江陵",              //   표지 도장 글자 (D+ 를 셀 수 없는 여행만, 없으면 seal)
      note: "초당에서 중앙시장까지", //   첫 장 손글씨 한 줄
      labels: { "chahyunhee-sundubu": "초당" }   // 지도 카드에 붙일 짧은 지명 { 장소 id: 이름 }
    },
    period: "10.18 SUN — 10.19 MON",
    nights: "1박 2일",
    days: [ ... ]
  };
})());
```

장소 한 줄은 이렇게 생겼습니다.

```js
{ id: "ojukheon", name: "오죽헌", en: "OJUKHEON", next: "차 10분", lat: 37.77930, lng: 128.87850 }
```

- `id`: 사진과 기록을 연결하는 키. 사진을 넣은 뒤에는 바꾸지 마세요.
- `name`: 화면에 보이는 이름
- `en`: 이름 아래 작은 영문 표기 (선택)
- `next`: 다음 장소까지의 이동 수단과 시간 (선택)
- `lat`, `lng`: 지도 핀 좌표. 없으면 지도에 표시되지 않습니다. 네이버/카카오/구글 지도에서 장소를 길게 누르거나 우클릭하면 좌표를 복사할 수 있습니다.
- `approx: true`: 추정 위치라는 안내를 팝업에 붙입니다. 숙소 좌표는 파일 맨 위 `HOTEL`에서 한 번에 바꿀 수 있습니다.


## 파일 구성

```
index.html             홈 화면 (여행 목록)
trip.html              여행 페이지 뼈대 (?trip=<id>)
css/style.css          공통 스타일 (종이 질감, 타임라인, 카드, 지도, 사진 보기)
css/home.css           홈 화면 스타일
js/trips/manifest.js   여행 파일 목록(TRIP_FILES), 사진 서버 설정(DIARY_CONFIG), 스크립트 로더
js/trips/gangneung.js  강릉여행 일정
js/home.js             홈 화면: 여행 다이어리(펼치기), 동선 지도, 서버에서 사진 수·사진
js/trip-boot.js        여행 페이지: 주소의 ?trip= 로 여행을 고르고 아래 스크립트를 불러옴
js/net-alert.js        상단 바의 붉은 ! (사진 서버 연결 문제 안내, 두 페이지 공통)
js/db.js               IndexedDB 래퍼 (브라우저 모드)
js/remote.js           서버 저장소 (서버 모드)
js/app.js              여행 페이지 화면 구성과 상호작용, 지도
.nojekyll              GitHub Pages 가 파일을 가공하지 않도록 하는 표시
```
